## Executive Summary

Massava führt ein **Hybrid-Modell** ein, das die Vorteile von Free-Tier-Netzwerkeffekten mit Premium-Monetarisierung kombiniert. Das Kernkonzept: **Großzügiger Trial → Paid oder Limited Free**.

### Kernprinzipien

1. **Trial First**: 30-60 Tage ALLE Features (inkl. Spontan-Termine)
2. **Smart Downgrade**: Nach Trial wählen zwischen Paid oder Limited Free
3. **Pain Points ohne Limits**: Kein Buchungslimit, aber strategische Feature-Gaps
4. **Regional Flexibilität**: Trial-Dauer angepasst an Marktreife

### Erwartete Outcomes

- **Conversion Rate**: 15-25% (Industry: 10-15%)
- **ARPU**: €18-22/Monat
- **Churn Rate**: <5%/Monat
- **Payback Period**: 4-6 Monate

## 2. Pricing-Strategie

### 2.1 Neue Preispunkte

#### Essential: €19,99/Monat
**Zielgruppe**: Einzelunternehmer, kleine Studios (1-2 Personen)

**Kernnutzen**:
- Spontan-Termine aktiviert → Mehr Auslastung
- In Spontan-Suche sichtbar → Neue Kunden
- Booking-Page & Visitenkarte → Professionelles Auftreten

**Value Proposition**:
> "Für weniger als €20/Monat: Fülle deine freien Slots automatisch und gewinne neue Kunden über die Spontan-Suche."

**Break-Even**: 1-2 zusätzliche Spontan-Buchungen/Monat

---

#### Pro: €39,99/Monat
**Zielgruppe**: Wachsende Studios, Multi-Mitarbeiter-Betriebe

**Kernnutzen**:
- Alles aus Essential
- Multi-Mitarbeiter Management
- Premium-Platzierung in Suche
- Erweiterte Analytics & Prognosen
- Prioritäts-Support

**Value Proposition**:
> "Für Teams: Verwalte mehrere Mitarbeiter, optimiere deine Auslastung und wachse schneller mit Premium-Sichtbarkeit."

**Break-Even**: 2-3 zusätzliche Buchungen/Monat

---

### 2.2 Preispsychologie

#### Unter €20-Schwelle (Essential)
- **Impuls-Kauf-Grenze**: €19,99 fühlt sich "klein" an
- **Mentale Schwelle**: Unterschied zwischen "unter 20" und "über 20" ist massiv
- **Vergleich**: Weniger als 1 Stunde Arbeit im Dienstleistungssektor

#### Doppel-Pricing-Strategie (Pro)
- **Verankerung**: €39,99 wirkt "fair" neben €19,99 (2x Preis, 3x Features)
- **Premium-Wahrnehmung**: Klare Differenzierung für ernsthafte Businesses
- **Upgrade-Pfad**: Natürlicher Growth Path für erfolgreiche Studios

---

### 2.3 Regional Angepasste Trial-Dauer

| Region/Stadt | Trial-Dauer | Begründung |
|--------------|-------------|------------|
| **Pilotregion Karlsruhe** | **60 Tage** | Henne-Ei-Problem: Wenig Studios → wenig User → wenig Wert. Längerer Trial kompensiert fehlende Netzwerkeffekte initial. |
| **Expansion-Städte** | **45 Tage** | Moderate Adoption → Mittlerer Trial für Markttests. |
| **Etablierte Märkte** | **30 Tage** | Hohe Studio-Dichte → Schneller Value → Kürzerer Trial. |
| **Enterprise/Ketten** | **90 Tage + Custom** | Längere Evaluationszyklen, individueller Support. |

**Implementierung**:
- Trial-Dauer als Studio-Attribut in DB: `trialDurationDays INT DEFAULT 30`
- Admin-Interface zur regionalen Anpassung
- Automatische Anpassung basierend auf Studio-Location

## 3. Pain Points im Limited Free Tier

### 3.1 Philosophie: "No Limits, But Strategic Gaps"

**NICHT tun**: Buchungslimits (z.B. "nur 10 Buchungen/Monat")
- **Warum**: Frustriert User, tötet Word-of-Mouth, schlechte UX

**STATTDESSEN**: Feature-Gaps die echten Business-Schmerz erzeugen

---

### 3.2 Kernprinzip: Spontan-Termine als Differentiator

**Spontan-Termine** (ehemals "Deals") ist das TGTG-Kernfeature:
- **Problem gelöst**: Leere Slots kosten Geld
- **Lösung**: Last-Minute-Buchungen mit flexiblen Preisen
- **Business Impact**: Direkt messbar in €€€

#### Warum Spontan-Termine der perfekte Pain Point ist:

1. **Sichtbarer Verlust**: User sehen leere Slots → Wissen, dass sie Geld verlieren
2. **FOMO-Mechanik**: "Andere Studios füllen ihre Slots, ich nicht"
3. **Direkter ROI**: Jeder Spontan-Termin = Beweis, dass Feature €€€ bringt
4. **Netzwerkeffekt**: Mehr Studios mit Spontan → Mehr User checken Feature → Mehr Wert

---

### 3.3 Konkrete Pain Points

#### Pain Point 1: Unsichtbarkeit in Spontan-Suche
**Free User sieht**:
```
❌ Dein Studio erscheint NICHT in der Spontan-Suche
ℹ️  Potenzielle Kunden suchen gerade nach Last-Minute-Terminen
💡 Aktiviere Spontan-Termine für €19,99/Monat
```

**Impact**:
- Direkter Umsatzverlust
- Konkurrenz ist sichtbar
- Messbar: X User haben heute in deiner Stadt nach Spontan-Terminen gesucht

---

#### Pain Point 2: Kann keine Spontan-Termine erstellen
**UI in Calendar-View**:
```
📅 Morgen, 14:00-15:00 | FREI | Noch nicht gebucht

[Spontan-Termin erstellen] 🔒 ESSENTIAL
└─ "Fülle diesen Slot mit einem Spontan-Termin und erreiche
    spontane Kunden in deiner Region"
```

**Impact**:
- Sieht leere Slots
- Weiß, dass Feature existiert (hat es im Trial genutzt)
- Kann aktiv nichts dagegen tun

---

#### Pain Point 3: Entgangener Umsatz Dashboard (FOMO)
**Free Dashboard zeigt**:
```
📊 Deine Statistiken (Diese Woche)

✅ Reguläre Buchungen: 12 (€840)
❌ Spontan-Termine: -
   └─ 🔒 Feature nicht aktiv

💰 Entgangener Umsatz (Schätzung):

   Diese Woche hätten 3-5 Studios in deiner Nähe mit
   Spontan-Terminen durchschnittlich €180-€320 zusätzlich
   verdient.

   [Spontan-Termine aktivieren für €19,99/Monat] →
```

**Impact**:
- Konkrete Zahlen → Rational greifbar
- Social Proof → "Andere verdienen damit Geld"
- ROI-Kalkulation → "€20 investieren → €180-320 bekommen"

---

#### Pain Point 4: Keine dynamischen Preise
**Free User kann**:
- Feste Preise für Services setzen: ✅
- Preise für einzelne Slots anpassen: ❌

**Use Case**:
- Will Montag-Vormittag günstiger anbieten → NEIN
- Will Samstag-Abend Premium-Preis → NEIN
- Will Last-Minute 30% Rabatt → NEIN

**Essential/Pro User kann**:
```
Spontan-Termin erstellen:
├─ Regulärer Preis: €70
├─ Spontan-Preis: €49 (-30%)
├─ Gültig bis: 2h vor Termin
└─ Auto-Deaktivierung bei Buchung
```

---

#### Pain Point 5: Kein Push bei Spontan-Anfragen
**Scenario**:
1. User sucht in App nach Spontan-Terminen in deiner Stadt
2. Free Studio: Erscheint NICHT in Ergebnissen → KEINE Anfrage → KEIN Push
3. Essential Studio: Erscheint in Ergebnissen → Buchungs-Anfrage → **Instant Push** 🔔

**Impact**:
- Zeit-sensitive Opportunities
- "Snooze = Lose" bei Last-Minute-Buchungen
- Konkurrenz ist schneller

---

#### Permission Checker Service

```typescript
// lib/subscriptions/permission-checker.ts

export class SubscriptionPermissionChecker {
  constructor(private subscription: StudioSubscription) {}

  /**
   * Check if studio can create spontaneous slots
   */
  canCreateSpontaneousSlots(): boolean {
    return this.subscription.features.spontaneous_slots;
  }

  /**
   * Check if studio is visible in spontaneous search
   */
  isVisibleInSpontaneousSearch(): boolean {
    return this.subscription.features.spontaneous_search_visible;
  }

  /**
   * Check if studio can use dynamic pricing
   */
  canUseDynamicPricing(): boolean {
    return this.subscription.features.dynamic_pricing;
  }

  /**
   * Check if studio can add multiple staff members
   */
  canAddMultipleStaff(): boolean {
    return this.subscription.features.multi_staff;
  }

  /**
   * Get booking limit (null = unlimited)
   */
  getBookingLimit(): number | null {
    return this.subscription.features.booking_limit;
  }

  /**
   * Check if trial is active
   */
  isInTrial(): boolean {
    if (!this.subscription.isTrial) return false;
    if (!this.subscription.trialEndDate) return false;
    return new Date() < this.subscription.trialEndDate;
  }

  /**
   * Get days remaining in trial
   */
  getTrialDaysRemaining(): number | null {
    if (!this.isInTrial() || !this.subscription.trialEndDate) return null;

    const now = new Date();
    const end = this.subscription.trialEndDate;
    const diffMs = end.getTime() - now.getTime();
    const diffDays = Math.ceil(diffMs / (1000 * 60 * 60 * 24));

    return Math.max(0, diffDays);
  }

  /**
   * Check if studio needs to upgrade for a feature
   */
  needsUpgradeFor(feature: keyof SubscriptionFeatures): boolean {
    return !this.subscription.features[feature];
  }

  /**
   * Get upgrade CTA message for a feature
   */
  getUpgradeCTA(feature: keyof SubscriptionFeatures): string {
    const messages: Record<keyof SubscriptionFeatures, string> = {
      spontaneous_slots: 'Aktiviere Spontan-Termine für €19,99/Monat und fülle deine freien Slots automatisch.',
      spontaneous_search_visible: 'Erscheine in der Spontan-Suche und erreiche spontane Kunden in deiner Region.',
      dynamic_pricing: 'Nutze dynamische Preise um deine Auslastung zu optimieren.',
      booking_page: 'Erstelle deine eigene Booking-Page und teile sie überall.',
      digital_business_card: 'Präsentiere dein Studio professionell mit einer digitalen Visitenkarte.',
      multi_staff: 'Verwalte mehrere Mitarbeiter und skaliere dein Business.',
      advanced_statistics: 'Erhalte detaillierte Einblicke und Prognosen für dein Business.',
      premium_placement: 'Erhalte Premium-Platzierung in Suchergebnissen.',
      priority_support: 'Erhalte vorrangigen Support bei Fragen und Problemen.',
      // ... andere features
      booking_system: '',
      booking_limit: '',
      push_notifications: '',
      email_notifications: '',
      basic_statistics: '',
    };

    return messages[feature] || 'Upgrade für mehr Features';
  }
}
```

## 11. Anhang

### 11.1 Glossar

- **ARPU**: Average Revenue Per User (Durchschnittlicher Umsatz pro User)
- **MRR**: Monthly Recurring Revenue (Monatlich wiederkehrender Umsatz)
- **ARR**: Annual Recurring Revenue (Jährlich wiederkehrender Umsatz)
- **LTV**: Lifetime Value (Gesamter Wert eines Users über die gesamte Kundenbeziehung)
- **CAC**: Customer Acquisition Cost (Kosten zur Gewinnung eines Neukunden)
- **Churn**: Kundenabwanderungsrate
- **FOMO**: Fear Of Missing Out (Angst etwas zu verpassen)
- **Trial**: Testzeitraum mit vollen Features
- **Spontan-Termine**: Last-Minute-Buchungsangebote (ehemals "Deals")
